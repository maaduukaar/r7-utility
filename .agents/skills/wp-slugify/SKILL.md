# Стандартизированная генерация слагов WordPress (`wp-slugify`)

Скилл и утилита предназначены для **детерминированной и безошибочной генерации ярлыков (slugs)** для статей (`post`), рубрик (`category`), тегов документации (`taxonomy=doc_tag`) и правил 301-редиректов в WordPress по эталонной схеме транслитерации портала Р7-Офис (плагин **Cyr-To-Lat**, стандарт **ISO 9 / ГОСТ 7.79-2000, Система B**).

---

## 📌 Когда применять

Используй этот навык всякий раз, когда требуется:
* **Создание слагов статей и документов:** подготовка `post_name` из кириллического заголовка и формирование имен файлов черновиков (например, `kak-nastroit-server.wp`).
* **Управление рубриками (`category`):** генерация одиночных или иерархических ярлыков разделов (`parent-slug/child-slug`).
* **Теги документации (`taxonomy=doc_tag`):** создание стандартизированных тегов через OpenCLI, REST API или панель WordPress.
* **Правила 301-редиректов:** расчет целевых канонических слагов при переносе, обновлении или объединении статей.
* **Верификация и аудит:** проверка существующих ссылок на портале на предмет отклонений от стандарта.

---

## 📐 Эталонные правила транслитерации (Cyr-To-Lat / ISO 9 B)

WordPress «из коробки» не выполняет транслитерацию кириллицы (превращает её в `%d0%bd...`). Для портала принята строгая схема **Cyr-To-Lat**:

### 1. Таблица сопоставления символов:

* **Специфические согласные:**
  * `Ц / ц` ➔ `ts` *(строго `ts`, не `c`)*
  * `Ч / ч` ➔ `ch`
  * `Ш / ш` ➔ `sh`
  * `Щ / щ` ➔ `shh` *(строго `shh`, не `sh` и не `sch`)*
  * `Ж / ж` ➔ `zh`
* **Гласные йотированные и специфические:**
  * `Я / я` ➔ `ya` *(строго `ya`, не `ja`)*
  * `Ю / ю` ➔ `yu` *(строго `yu`, не `u`)*
  * `Ё / ё` ➔ `yo`
  * `Э / э` ➔ `e`
  * `Ы / ы` ➔ `y`
* **Буква Й:**
  * `Й / й` ➔ `j` *(строго `j`, не `y` и не `i`)*
* **Знаки разделения и мягкости:**
  * `Ъ / ъ` и `Ь / ь` ➔ `""` *(полностью удаляются, пустая строка)*
* **Базовые согласные и гласные:**
  * `А`➔`a`, `Б`➔`b`, `В`➔`v`, `Г`➔`g`, `Д`➔`d`, `Е`➔`e`, `З`➔`z`, `И`➔`i`,
  * `К`➔`k`, `Л`➔`l`, `М`➔`m`, `Н`➔`n`, `О`➔`o`, `П`➔`p`, `Р`➔`r`, `С`➔`s`,
  * `Т`➔`t`, `У`➔`u`, `Ф`➔`f`, `Х`➔`h`.

### 2. Алгоритм нормализации:
1. Посимвольная замена кириллицы по таблице сопоставления.
2. Приведение всей строки к нижнему регистру (`lowercase`).
3. Замена знаков препинания и разделителей `.` (точка), `/` (слэш), `_` (подчёркивание) на дефис `-`.
4. Удаление всех недопустимых знаков (все, кроме `a-z`, цифр `0-9`, пробелов и дефисов: `[^a-z0-9 -]`).
5. Схлопывание повторяющихся пробелов и дефисов в один дефис (`-+` ➔ `-`).
6. Удаление дефисов на концах строки (`strip('-')`).

## 🎯 Специфика сущностей

1. **Статьи (Posts):**
   * Вход: `"Работа с диаграммами"`
   * Выход: `rabota-s-diagrammami`
   * Обновление URL с сохранением категорий: `/documents/calc/old-slug/` ➔ `/documents/calc/rabota-s-diagrammami/`
2. **Рубрики (Categories):**
   * Вход: `"Электронные таблицы"`
   * Выход: `elektronnye-tablitsy` (или иерархический путь `parent/child`)
3. **Теги документации (doc_tag):**
   * Вход: `"Текст и выделение"`
   * Выход: `tekst-i-vydelenie`

## 💻 Готовая эталонная функция (Python)

```python
import re

CYR_TO_LAT_MAP = {
    'А': 'A', 'Б': 'B', 'В': 'V', 'Г': 'G', 'Д': 'D', 'Е': 'E', 'Ё': 'YO',
    'Ж': 'ZH', 'З': 'Z', 'И': 'I', 'Й': 'J', 'К': 'K', 'Л': 'L', 'М': 'M',
    'Н': 'N', 'О': 'O', 'П': 'P', 'Р': 'R', 'С': 'S', 'Т': 'T', 'У': 'U',
    'Ф': 'F', 'Х': 'H', 'Ц': 'TS', 'Ч': 'CH', 'Ш': 'SH', 'Щ': 'SHH',
    'Ъ': '',  'Ы': 'Y', 'Ь': '',  'Э': 'E', 'Ю': 'YU', 'Я': 'YA',
    'а': 'a', 'б': 'b', 'в': 'v', 'г': 'g', 'д': 'd', 'е': 'e', 'ё': 'yo',
    'ж': 'zh', 'з': 'z', 'и': 'i', 'й': 'j', 'к': 'k', 'л': 'l', 'м': 'm',
    'н': 'n', 'о': 'o', 'п': 'p', 'р': 'r', 'с': 's', 'т': 't', 'у': 'u',
    'ф': 'f', 'х': 'h', 'ц': 'ts', 'ч': 'ch', 'ш': 'sh', 'щ': 'shh',
    'ъ': '',  'ы': 'y', 'ь': '',  'э': 'e', 'ю': 'yu', 'я': 'ya'
}

def wp_slugify(text: str) -> str:
    if not text:
        return ""
    translit = "".join(CYR_TO_LAT_MAP.get(ch, ch) for ch in text)
    slug = translit.lower()
    slug = re.sub(r"[._/]", "-", slug)
    slug = re.sub(r"[^a-z0-9 -]", "", slug)
    slug = re.sub(r"\s+", "-", slug)
    slug = re.sub(r"-+", "-", slug)
    return slug.strip("-")
```
