Стандарты и логика

Как устроен алгоритм Cyr-To-Lat и правила транслитерации ISO 9

J

Почему буква «й» транслитерируется как «j»?

В англо-ориентированных правилах (например, МВД РФ для загранпаспортов) звук «й» передается как «i» или «y». Однако в международном стандарте ISO 9 и ГОСТ 7.79-2000 (Система B) соблюдается принцип однозначного соответствия:

  • Латинская буква «y» строго зарезервирована за гласной «ы» (бык ➔ byk).
  • Согласный звук «й» по славянской традиции передается буквой «j» (настройка ➔ nastrojka).
  • Знаки «ъ» и «ь» полностью опускаются.

Как работает связка Cyr-To-Lat и ядра WordPress

WordPress «из коробки» не поддерживает транслитерацию кириллицы: встроенная функция remove_accents() умеет очищать только западноевропейские диакритические знаки (é ➔ e). Без плагина кириллические заголовки превращаются в процентный код (%d0%bd...).

Плагин Cyr-To-Lat перехватывает хук sanitize_title до очистки, меняет буквы по таблице ISO 9, после чего стандартный sanitize_title_with_dashes() ядра удаляет скобки, кавычки и заменяет пробелы на дефисы.

Гибридный перевод: Словарь Р7 + нейросеть NMT

В режиме «Перевод» действует интеллектуальный двухуровневый конвейер:

  • Приоритет словаря Р7 (0 мс): термины портала базы знаний, устойчивые фразы и названия продуктов переводятся мгновенно без сетевых задержек.
  • Клиентская NMT-модель (Transformers.js): редкие и составные термины автоматически переводятся нейросетью MarianMT (opus-mt-ru-en) локально в браузере через WebAssembly/ONNX — без отправки данных на сервер.
  • Умное кэширование: каждый переведённый термин сохраняется в локальное хранилище браузера (localStorage) и в последующие разы применяется мгновенно.

function wpSlugify(text) {
  if (!text) return '';

  let transliterated = '';
  for (const char of text) {
    transliterated += CYR_TO_LAT_MAP[char] !== undefined ? CYR_TO_LAT_MAP[char] : char;
  }

  const clean = transliterated
    .toLowerCase()
    .replace(/[._/]/g, '-')
    .replace(/[^a-z0-9 -]/g, '')
    .trim()
    .replace(/\s+/g, '-')
    .replace(/-+/g, '-')
    .replace(/^-+|-+$/g, '');

  return clean || '';
}

CYR_TO_LAT_MAP = {
    'А': 'A', 'Б': 'B', 'В': 'V', 'Г': 'G', 'Д': 'D', 'Е': 'E', 'Ё': 'YO',
    'Ж': 'ZH', 'З': 'Z', 'И': 'I', 'Й': 'J', 'К': 'K', 'Л': 'L', 'М': 'M',

    'ф': 'f', 'х': 'h', 'ц': 'ts', 'ч': 'ch', 'ш': 'sh', 'щ': 'shh',
    'ъ': '', 'ы': 'y', 'ь': '', 'э': 'e', 'ю': 'yu', 'я': 'ya'
}

def wp_slugify(text: str) -> str:
    if not text:
        return ""
    translit = "".join(CYR_TO_LAT_MAP.get(ch, ch) for ch in text)
    slug = translit.lower()
    slug = re.sub(r"[._/]", "-", slug)
    slug = re.sub(r"[^a-z0-9 -]", "", slug)
    slug = re.sub(r"\s+", "-", slug)
    slug = re.sub(r"-+", "-", slug)
    clean = slug.strip("-")
    return clean
