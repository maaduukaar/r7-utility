Всё о стандартах транслитерации и архитектуре слагов

Почему слаг выглядит именно так, чем стандарты отличаются друг от друга и как устроен этот механизм в WP.

J

Почему «й» ➔ «j», а не «y» или «i»?

В англо-ориентированных транслитерациях (например, МВД для загранпаспортов) «й» часто пишут как «i» или «y» (Mayak, Tolstoy). Но в международном стандарте ISO 9 и ГОСТ 7.79-2000 (Система B) принят строгий лингвистический принцип: каждой букве соответствует свой уникальный звук латиницы без диакритики.

Поскольку буква «Y» зарезервирована за «Ы» (бык ➔ byk), для согласного звука «Й» используется классическая славянская буква «J» (как в чешском, польском, сербском). Отсюда: «Настройка» ➔ «nastrojka».

История: Rus-To-Lat ➔ Cyr-To-Lat

В конце 2000-х годов разработчик Антон Скоробогатов создал концепт Rus-To-Lat. Позже Сергей Бирюков (ключевой контрибьютор русской локализации WordPress) превратил его в официальный плагин Cyr-To-Lat на WordPress.org.

Позже проект развивали Михаил Кобзарев (mihdan) и Ивижан Стефан Стипич (Cyr to Lat Enhanced). За более чем 15 лет этот плагин установлен на сотнях тысяч сайтов и стал непререкаемым стандартом генерации ЧПУ в Рунете.

Почему ядро WP само не транслитерирует?

В ядре WordPress есть встроенная функция remove_accents(). Но она поддерживает исключительно романские/европейские акценты (é ➔ e, ü ➔ u, ñ ➔ n). Кириллицу она игнорирует.

Если плагин транслитерации не установлен, то вызов sanitize_title_with_dashes() превращает русские слова в громоздкий процентный код (%d0%bd%d0%b0...), который ломает короткие читаемые ссылки в документациях и статьях.

function wpSlugify(text) {
  if (!text) return '';

  // 1. Посимвольная транслитерация (ISO 9 / Cyr-To-Lat)
  let transliterated = '';
  for (const char of text) {
    transliterated += CYR_TO_LAT_MAP[char] !== undefined ? CYR_TO_LAT_MAP[char] : char;
  }

  // 2. Логика WordPress sanitize_title_with_dashes
  return transliterated
    .toLowerCase()
    .replace(/[._/]/g, '-')          // точки, слэши, подчеркивания в дефис
    .replace(/[^a-z0-9 -]/g, '')     // удаление скобок, кавычек и спецсимволов
    .trim()
    .replace(/\s+/g, '-')            // пробелы в дефис
    .replace(/-+/g, '-')             // схлопывание повторных дефисов
    .replace(/^-+|-+$/g, '');        // обрезка дефисов по краям
}

import re

CYR_TO_LAT_MAP = {
    'А': 'A', 'Б': 'B', 'В': 'V', 'Г': 'G', 'Д': 'D', 'Е': 'E', 'Ё': 'YO',
    'Ж': 'ZH', 'З': 'Z', 'И': 'I', 'Й': 'J', 'К': 'K', 'Л': 'L', 'М': 'M',

    'Ґ': 'G', 'ґ': 'g', 'Ў': 'U', 'ў': 'u'
}

def wp_slugify(text: str) -> str:
    if not text:
        return ""
    
    # 1. Транслитерация
    translit = "".join(CYR_TO_LAT_MAP.get(ch, ch) for ch in text)
    
    # 2. Нормализация WordPress
    slug = translit.lower()
    slug = re.sub(r"[._/]", "-", slug)
    slug = re.sub(r"[^a-z0-9 -]", "", slug)
    slug = re.sub(r"\s+", "-", slug)
    slug = re.sub(r"-+", "-", slug)
    return slug.strip("-")

# Проверка
