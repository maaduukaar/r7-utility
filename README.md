## Конвертер HTML-таблиц

Простое одностраничное веб-приложение для преобразования HTML-таблиц в формат, необходимый для сайта поддержки Р7-Офис.

### Основные возможности

- **Конвертация HTML**: Преобразует стандартные HTML-таблицы в специальный формат.
- **Простой интерфейс**: Поле для ввода/вывода кода и кнопки для управления (Преобразовать, Копировать, Очистить).
- **Валидация ввода**: Проверяет наличие таблицы во введенном коде.
- **Обратная связь**: Отображает сообщения об успехе или ошибках.
- **Форматирование кода**: Улучшает читаемость выходного HTML.

### Как использовать

1. Откройте [приложение](https://maaduukaar.github.io/r7-utility/table-converter.html).
2. Вставьте HTML-код вашей таблицы в текстовое поле.
3. Нажмите кнопку **"Преобразовать"**.
4. Результат появится в том же поле.
5. Нажмите **"Копировать"**, чтобы скопировать отформатированный код в буфер обмена.
6. Нажмите **"Очистить"**, чтобы очистить поле.

### Логика преобразования

- Вся таблица оборачивается в контейнер `div` с идентификатором `methodParams`.
- Первая строка (`<tr>`) исходной таблицы помещается в заголовок `<thead>`.
- Все последующие строки (`<tr>`) помещаются в тело таблицы `<tbody>`.


## Конвертер HTML-таблиц: вынос шапки в thead

Современная двухколоночная утилита для автоматического исправления разметки HTML-таблиц, у которых заголовок находится внутри `<tbody>` обычными строками, а тег `<thead>` отсутствует.

### Основные возможности

- **Двухпанельный редактор**: Удобный разделенный интерфейс с исходным кодом слева и результатом справа.
- **Мгновенная конвертация**: Автоматическая обработка на лету при вставке или вводе кода без лишних кликов.
- **Преобразование `<tr>` в `<th>`**: Первая строка из `<tbody>` переносится во вновь созданный `<thead>`, а все вложенные ячейки преобразуются в заголовочные `<th>` с сохранением исходных атрибутов.
- **Автоматическое копирование**: Результат сразу помещается в буфер обмена с визуальной индикацией.
- **Форматирование кода**: Очистка и выравнивание отступов итогового HTML-кода таблицы.

### Как использовать

1. Откройте [приложение](https://maaduukaar.github.io/r7-utility/table-converter-redisign.html).
2. Вставьте исходный HTML-код таблицы в левое поле.
3. Готовый HTML со сформированным `<thead>` мгновенно появится в правом поле и скопируется в буфер обмена.


## Обработчик HTML-ссылок

Простое одностраничное веб-приложение для автоматического добавления атрибута target="_blank" к ссылкам в HTML-коде, чтобы они открывались в новой вкладке.

### Основные возможности
- **Обработка ссылок**: Автоматически добавляет target="_blank" и rel="noopener" ко всем ссылкам, которые не ведут на изображения.
- **Простой интерфейс**: Единое поле для ввода/вывода кода и кнопки для управления (Обработать, Копировать, Очистить).
- **Игнорирование изображений**: Утилита не модифицирует ссылки, ведущие на файлы изображений (.jpg, .png, .svg и т.д.).
- **Обратная связь**: Отображает визуальное подтверждение обработки (изменение цвета фона) и уведомление об успешном копировании.
- **Автокопирование**: Результат автоматически копируется в буфер обмена сразу после обработки.

### Как использовать

1. Откройте [приложение](https://maaduukaar.github.io/r7-utility/add-target-blank.html).
2. Вставьте ваш HTML-код в текстовое поле.
3. Нажмите кнопку "Обработать".
4. Результат появится в том же поле и будет автоматически скопирован в буфер обмена.
5. Нажмите "Копировать", если нужно повторно скопировать отформатированный код.
6. Нажмите "Очистить", чтобы очистить поле для нового кода.

### Логика работы

- Утилита парсит введенный HTML-код и находит все теги <a> с атрибутом href.
- Для каждой найденной ссылки проверяется, не заканчивается ли ее адрес на расширение файла изображения.
- Если ссылка не является ссылкой на изображение, скрипт добавляет ей атрибуты target="_blank" и rel="noopener".
- Если в ссылке есть атрибут target="_self", он перезаписывается на target="_blank".
- Существующие атрибуты rel не перезаписываются, а корректно дополняются.
- Обновленный HTML-код выводится в то же текстовое поле.


## Инструмент сравнения списков

Одностраничное веб-приложение для быстрого построчного сравнения двух списков (например, перечней функций, названий статей, идентификаторов или параметров) и выявления расхождений.

### Основные возможности

- **Двухколоночный ввод**: Поля для «Оригинала» и «Копии» с автоматической нормализацией (очистка пробелов, точек с запятой, точек на конце и приведение к единому регистру).
- **Многомерный анализ расхождений**:
  - Элементы, пропущенные в копии (есть только в оригинале).
  - Элементы, отсутствующие в оригинале (новые в копии).
  - Элементы, общие для обоих списков.
- **Копирование в один клик**: Нажатие на любой блок результатов копирует отсортированный список расхождений в буфер обмена.
- **Индикация идентичности**: Моментальное визуальное подтверждение при полном совпадении списков.

### Как использовать

1. Откройте [приложение](https://maaduukaar.github.io/r7-utility/list-diff-checker.html).
2. Вставьте первый список в поле «Оригинал», второй — в поле «Копия».
3. Нажмите кнопку **"Сравнить списки"**.
4. Кликните по нужному блоку результата, чтобы скопировать расхождения.


## Генератор слагов WordPress (Cyr-To-Lat / ISO 9)

Минималистичное веб-приложение в стиле Apple для мгновенной генерации эталонных URL-ярлыков (slug / post_name) из кириллических заголовков в строгом соответствии с плагином **Cyr-To-Lat** и стандартом **ISO 9 (ГОСТ 7.79-2000, Система B)**.

### Основные возможности

- **Минималистичный дизайн в стиле Apple Spotlight**: Единая поисковая строка по центру экрана без лишнего визуального шума.
- **Динамическая адаптивная ширина**: Поле ввода плавно расширяется под длину заголовка вплоть до краёв экрана минус 20 пикселей (`calc(100vw - 40px)`).
- **Мгновенное управление с клавиатуры**:
  - `Enter` — формирует слаг и автоматически копирует его в буфер обмена.
  - `Backspace` — возвращает исходный заголовок для редактирования.
  - `Esc` — мгновенно очищает строку.
- **Стандарт Cyr-To-Lat / ISO 9**: Строгое соблюдение транслитерации (буква «й» -> «j», «ы» -> «y», знаки «ъ»/«ь» опускаются).
- **Режимы «Статьи» и «Рубрики»**: Быстрое переключение режимов для генерации слагов статей с поддержкой замены старого полного пути или рубрик с суффиксом раздела.
- **Справка и сниппеты кода**: Отдельные модальные разделы со сравнительным анализом систем транслитерации, интерактивной картой алфавита и готовыми примерами кода на JavaScript, PHP и Python.

### Как использовать

1. Откройте [приложение](https://maaduukaar.github.io/r7-utility/wp-slug-generator.html).
2. Выберите режим работы (клик по иконке слева):
   - **Статьи**: для заголовков статей (поддерживается замена старого полного слага в подбаре).
   - **Рубрики**: для названий разделов (поддерживается применение суффикса раздела).
3. Вставьте или введите заголовок и нажмите **Enter**.
4. Сгенерированный слаг автоматически скопируется в буфер обмена.
5. Для правки нажмите **Backspace**, для быстрой очистки поля — **Del**, для отмены — **Esc**.
